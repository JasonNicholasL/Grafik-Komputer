Kalkulator Kamera 3D: Perhitungan Step-by-Step

Sistem breakdown matematika grafika komputer untuk pembentukan ruang kamera perspektif secara utuh.

Parameter Utama

Visualisasi Kedudukan Kamera

Seret dengan mouse untuk mengorbit ruang simulasi.

*Garis Kuning: Frustum Volume Kamera. Titik Merah: Titik Target $\vec{T}$.

Matriks Akhir (Column-Major)

Susunan data linear 1D siap pakai di WebGL / OpenGL.

Matriks View ($M_{view}$)
Matriks Proyeksi ($M_{proj}$)

Langkah demi Langkah Pembentukan Matriks View ($M_{view}$)

LANGKAH 1: Hitung Vektor Arah Kamera ($\vec{z}$)

LANGKAH 2: Hitung Vektor Kanan Kamera ($\vec{x}$) Menggunakan Cross Product

LANGKAH 3: Hitung Vektor Atas Kamera Sebenarnya ($\vec{y}$) Menggunakan Cross Product

LANGKAH 4: Hitung Komponen Translasi Posisi Kamera Kamera (Dot Product)

Langkah demi Langkah Pembentukan Matriks Proyeksi Perspektif ($M_{proj}$)

LANGKAH 1: Hitung Focal Scale ($f_{scale}$) Berdasarkan FOV $\theta$

LANGKAH 2: Hitung Elemen Utama Matriks Proyeksi ($m_{0,0}, m_{1,1}, m_{2,2}, m_{3,2}$)
